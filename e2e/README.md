# ชุดทดสอบเส้นทางผู้ใช้จริง (E2E)

เปิดเบราว์เซอร์จริง กดจริง อ่านหน้าจอจริง — เป็นหลักฐานระดับ **"วัดแล้ว"**
ต่างจาก `npm run verify` ที่ตรวจว่า *โค้ดถูกไหม* ชุดนี้ตรวจว่า **คนใช้ได้ไหม**

> กติกาข้อ 5 ของโปรเจกต์: `build`/`typecheck` ผ่าน **ไม่ใช่หลักฐานว่าหน้าใช้ได้**
> หน้า `force-dynamic` ไม่ถูก render ตอน build เลย ชุดนี้จึงเป็นด่านเดียวที่ครอบตรงนั้น

## รันยังไง

```bash
# ยิงใส่ production (ค่าเริ่มต้น) — อ่านอย่างเดียว ไม่แตะข้อมูลใคร
npm run e2e:public

# ยิงใส่เครื่องตัวเอง (ต้อง npm run build && npx next start ก่อน)
E2E_BASE_URL=http://127.0.0.1:3000 npm run e2e:public

# รวมเส้นทางหลังล็อกอินด้วย (ต้องมีบัญชีทดสอบ)
TEST_EMAIL=... TEST_PASSWORD=... npm run e2e
```

## มีอะไรบ้าง

| ไฟล์ | ครอบอะไร |
|---|---|
| `public-journeys.spec.ts` | คนที่ยังไม่สมัคร — หน้าแรกสื่อสารได้ไหม · เห็นราคาไหม · ลิงก์กฎหมายตายไหม · หน้าลองใช้คำนวณถูกไหม · ทุกหน้าตอบเร็วพอไหม · มือถือล้นจอไหม · ปุ่มกดได้ด้วยนิ้วไหม |
| `logged-in-journeys.spec.ts` | ลูกค้าที่จ่ายเงินแล้ว — ทุกเมนูกดแล้วไปถึงจริงไหม · เจอจอ error ไหม · ปุ่มดูตัวอย่างเอกสารทำงานไหม · มือถือล้นจอไหม |

รันบน 2 โปรเจกต์เสมอ: **มือถือ** (Pixel 7) มาก่อน **เดสก์ท็อป** เพราะผู้ใช้หลักของเราอยู่บนมือถือ

## กฎเหล็กของชุดนี้

1. **ห้ามสร้าง/แก้/ลบข้อมูลจริงบน production** — ทุกเทสต์อ่านอย่างเดียว
   ปุ่มที่กดได้คือปุ่มที่ไม่บันทึกอะไร (เช่น "ดูตัวอย่างเอกสาร" ที่เปิดหน้าต่างอ่านอย่างเดียว)
2. **ไม่มีรหัสทดสอบ = ข้ามพร้อมบอกเหตุผล ห้ามผ่านเงียบ ๆ**
   "ผ่าน" ทั้งที่ไม่ได้รัน อันตรายกว่าไม่รัน เพราะทำให้เข้าใจผิดว่าตรวจแล้ว
3. **เทสต์ตกต้องแยกให้ออกว่าเป็นบั๊กของระบบ หรือข้อจำกัดของเครื่องที่รัน**
   เช่น `/api/health` บนเครื่อง dev ที่ไม่มี service role key — ข้ามโดยตั้งใจ ไม่ใช่ระบบพัง

## เรื่อง proxy (เฉพาะเครื่องที่ออกเน็ตผ่าน proxy เท่านั้น)

`playwright.config.ts` อ่าน `HTTPS_PROXY` แล้วส่งเข้า Chromium เป็น argument
สองจุดที่เคยทำให้เสียเวลาหลายรอบ และเขียนกำกับไว้ในไฟล์ config แล้ว:

- ห้ามตั้ง `use.proxy` ของ Playwright คู่กับ args — มันทับ `--proxy-bypass-list`
- ค่า `--proxy-bypass-list=<-loopback>` แปลว่า **"ห้ามข้าม proxy สำหรับ loopback"**
  ซึ่งตรงข้ามกับที่ต้องการ ให้ระบุ `127.0.0.1;localhost` ตรง ๆ

อาการเวลาตั้งผิด **หลอกมาก**: `page.goto` ไม่ throw (ได้หน้า error ของ proxy มาแทน)
แต่หา element ไม่เจอสักตัว ทำให้ดูเหมือนหน้าเว็บพังทั้งเว็บ

## เครื่องที่ไม่มีเบราว์เซอร์ให้

ตั้ง `E2E_CHROME` ชี้ไปที่ Chromium ที่มีอยู่ ถ้าไม่ตั้งและไม่มีตัวที่ path เริ่มต้น
Playwright จะไปหาเบราว์เซอร์ของตัวเอง (ต้อง `npx playwright install` ครั้งเดียว)
